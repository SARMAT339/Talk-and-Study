## Обзор проекта

| Параметр | Значение |
|----------|----------|
| Название продукта | MouseCouncil |
| Отображаемое название | Аргъау |
| Движок | Unity 6000.1.16f1 |
| Рендер-пайплайн | Universal Render Pipeline (URP) 2D |
| Платформа | WebGL (основная), поддерживается редактор Unity |
| Ввод | Unity Input System (мышь + тач) |
| UI | TextMeshPro + программно создаваемые Canvas-панели |

**Идея:** три мыши по очереди бросают колокольчик в движущегося кота. При попадании — победа; при трёх промахах — поражение. Звуковые реплики на осетинском языке сопровождают игровой процесс.

## Запуск и сборка

### Запуск в редакторе Unity

1. Откройте папку `MouseCouncil/` через Unity Hub.
2. Откройте сцену `Assets/Scenes/SampleScene.unity`.
3. Нажмите **Play**.

При первом запуске отображается **главное меню** (`GamePhase.MainMenu`).

### Сборка WebGL

1. **File → Build Profiles** (или Build Settings).
2. Выберите профиль **Mouse Council** (`Assets/Settings/Build Profiles/Mouse Council.asset`) или платформу WebGL.
3. Укажите выходную папку — рекомендуется корень репозитория (`Talk-and-Study/`), чтобы обновить `Build/` и `index.html`.
4. Нажмите **Build**.

После сборки откройте `index.html` в браузере или разместите содержимое на статическом хостинге.

## Архитектура

Проект построен на **централизованном конечном автомате** в `GameManager` с вспомогательными компонентами для движения, физики и UI.

```
┌─────────────────────────────────────────────────────────┐
│                      GameManager                         │
│  (Singleton, фазы игры, ходы, победа/поражение)           │
└──────────┬──────────┬──────────┬──────────┬────────────┘
           │          │          │          │
     ┌─────▼─────┐ ┌──▼───┐ ┌────▼────┐ ┌───▼────────┐
     │ CameraMove│ │MenuUI│ │Sounds   │ │ BellSpawner│
     └───────────┘ └──────┘ │Controller│ └─────┬──────┘
                            └──────────┘       │
                    ┌──────────────────────────┼──────────────┐
                    │                          │              │
              ┌─────▼─────┐            ┌───────▼──────┐  ┌────▼────┐
              │ MouseAgent│ ×3         │BellController│  │Throwable│
              │ (×3 мыши) │            │  + Rigidbody2D│  │ Object  │
              └───────────┘            └──────────────┘  └─────────┘
```

### Паттерны

- **Singleton:** `GameManager.Instance`, `MenuUI.Instance`
- **Автопоиск ссылок:** `GameManager.AutoFindReferences()` находит объекты по имени, если поля не заданы в Inspector
- **Корутины:** асинхронные последовательности (интро, ход, промах, финал)
- **Legacy-совместимость:** `CharacterSwitcher` отключается при наличии `GameManager`; параметры переносятся в `MouseAgent`

## Игровой цикл и фазы

`GameManager.GamePhase` определяет текущее состояние:

| Фаза | Описание |
|------|----------|
| `MainMenu` | Главное меню (кнопки «Начать», «О разработчиках», «Выход») |
| `About` | Экран «О разработчиках» |
| `StartScreen` | Стартовый экран с тремя мышами, ожидание клика |
| `Intro` | Мыши бегут на игровые позиции, камера едет к сцене |
| `Playing` | Активные ходы: подход → бросок → результат |
| `Ending` | Завершение партии, возврат камеры |
| `Result` | Экран «Вы выиграли!» / «Вы проиграли!» |

### Диаграмма переходов

```
MainMenu ──► StartScreen ──► Intro ──► Playing ──► Ending ──► Result
    ▲            │                                              │
    │            │                                              │
    └────────────┴──────── ReturnToMainMenu ◄───────────────────┘
                 │
                 └── RestartGame (клик на Result)
About ◄──► MainMenu
```

### Логика хода (`TurnRoutine`)

1. Блокировка ввода (`inputLocked = true`).
2. Активная мышь (`mice[currentMouseIndex]`) идёт к точке подхода.
3. `BellSpawner.SpawnBellForTurn()` создаёт колокольчик.
4. Разблокировка ввода; ожидание броска (`BellController.WasThrown`).
5. После броска — `WaitThrowResultRoutine`:
   - попадание в объект с тегом `CAT` → `OnBellHitCat` → победа;
   - столкновение с тегом `Disable` или таймаут → `ResolveMiss` → следующий ход.

### Параметры баланса (Inspector → GameManager)

| Поле | По умолчанию | Описание |
|------|--------------|----------|
| `maxThrows` | 3 | Максимум бросков за партию |
| `endDelay` | 2 с | Пауза перед возвратом камеры |
| `throwResolveTimeout` | 6 с | Таймаут ожидания результата броска |
| `missSettleDelay` | 1.5 с | Задержка перед регистрацией промаха |

## Описание скриптов

### `GameManager.cs`

**Роль:** центральный контроллер игры.

**Ключевые методы:**

| Метод | Назначение |
|-------|------------|
| `EnterMainMenu()` | Сброс состояния, показ меню |
| `EnterStartScreen()` | Переход к стартовому экрану |
| `BeginIntro()` | Запуск интро (камера + бег мышей) |
| `StartTurn()` / `TurnRoutine()` | Один ход активной мыши |
| `OnBellThrown()` | Колокольчик брошен |
| `OnBellHitCat()` | Попадание — победа |
| `OnBellMissed()` | Промах |
| `RestartGame()` | Новая партия со стартового экрана |
| `ReturnToMainMenu()` | Возврат в меню |

UI экрана результата создаётся **программно** в `SetupResultUI()` при `Awake`.

### `MouseAgent.cs`

**Роль:** движение одной мыши между точками.

- Переключение визуалов `idleObject` / `runObject`.
- Отражение спрайта по направлению движения (`flipX`).
- `CaptureHomePosition()` — запоминает стартовую позицию для возврата после промаха.
- `MoveTo()`, `ReturnHome()`, `SnapToHome()`.

### `BellController.cs`

**Роль:** управление броском колокольчика.

- До броска: `Rigidbody2D.isKinematic = true`.
- Бросок активируется кликом **по колокольчику** (raycast).
- Направление: к `targetArea` (CatTarget) + случайное смещение `randomOffset` + компонента вверх.
- Сила броска: `force` (по умолчанию 10).

### `BellSpawner.cs`

**Роль:** создание экземпляра колокольчика на каждый ход.

- Префаб: `bellPrefab` или объект сцены `Bell_0`.
- Точка спавна: `spawnPoint`.
- Связывает `BellController` с `GameManager` и `ThrowableObject`.

### `ThrowableObject.cs`

**Роль:** обработка столкновений колокольчика.

```csharp
// Тег CAT  → OnBellHitCat  (победа)
// Тег Disable → OnBellMissed (промах)
```

Требует `Rigidbody2D` и коллайдер на колокольчике; на целевых объектах — соответствующие теги и коллайдеры.

### `CameraMove.cs`

**Роль:** плавное перемещение камеры между `startPosition` и `gamePosition`.

- `MoveToGame()` — переход к игровой сцене.
- `MoveToStartRoutine()` — возврат на стартовый экран.
- `SnapToStart()` — мгновенный сброс (при рестарте).

### `MenuUI.cs`

**Роль:** программное создание главного меню и экрана «О разработчиках».

- Singleton `MenuUI.Instance`.
- Кнопки вызывают методы `GameManager`.
- Текст «О разработчиках» хранится в константе `AboutBody`.

### `SoundsController.cs`

**Роль:** периодическое воспроизведение реплик мышей.

- Массив `mouseChatterClips` — аудиофайлы из `Assets/Sounds/`.
- Интервал между репликами: `minInterval`–`maxInterval` секунд.
- `StartMouseChatter()` вызывается при начале `Playing`; `StopMouseChatter()` — при завершении.

### `CharacterSwitcher.cs` (legacy)

**Роль:** устаревший скрипт движения мыши к одной цели по клику.

Автоматически **отключается**, если в сцене есть `GameManager`. Параметры (`idleObject`, `runObject`, `speed`) мигрируют в `MouseAgent`.

## Сцена и объекты

Основная сцена: `Assets/Scenes/SampleScene.unity`.

### Обязательные объекты (имена используются в автопоиске)

| Имя объекта | Назначение |
|-------------|------------|
| `GameManager` | Корневой объект с `GameManager`, `MenuUI`, `SoundsController`, `AudioSource` |
| `Main Camera` | Камера с `CameraMove` |
| `Mouse`, `Mouse2`, `Mouse3` | Три мыши (добавляется/используется `MouseAgent`) |
| `Target`, `Target2`, `Target3` | Точки подхода каждой мыши к колокольчику |
| `CatTarget` | Целевая точка броска (Transform для `BellController.targetArea`) |
| `Bell_0` | Шаблон колокольчика (префаб/объект сцены, изначально неактивен) |
| `StartText` | TMP-текст подсказки на стартовом экране |
| Объекты с тегом `CAT` | Коллайдеры тела кота (попадание) |
| Объекты с тегом `Disable` | Зоны промаха (границы, земля и т.п.) |

### Теги (ProjectSettings/TagManager.asset)

| Тег | Использование |
|-----|---------------|
| `CAT` | Попадание колокольчика в кота |
| `Disable` | Регистрация промаха при столкновении |

## Веб-сборка (WebGL)

### Структура деплоя

Для работы в браузере нужны:

- `index.html`
- папка `Build/` (loader, framework, data, wasm)
- папка `TemplateData/`

### index.html

- Размер canvas на десктопе: **960×600**.
- На мобильных устройствах canvas растягивается на весь экран.
- Кнопка полноэкранного режима вызывает `unityInstance.SetFullscreen(1)`.

### Рекомендации по WebGL

- Размещайте сборку на **HTTPS**-хостинге или локальном сервере (не `file://` — CORS и WASM могут блокироваться).
- Для уменьшения размера сборки настройте **Compression Format** в Player Settings.
- Проверяйте загрузку в Chrome DevTools → Console.

## Расширение проекта

### Добавить новую реплику мыши

1. Импортируйте `.wav` / `.mp3` в `Assets/Sounds/`.
2. Добавьте клип в массив `mouseChatterClips` на `SoundsController`.

### Изменить число попыток

Измените `maxThrows` в Inspector на `GameManager`. Логика ходов привязана к индексу мыши; для большего числа мышей добавьте объекты `Mouse4`, `Target4` и расширьте массивы в `BuildMiceFromScene()` / `BuildMouseTargets()`.

### Добавить новый экран меню

1. Создайте панель в `MenuUI.BuildMainMenu()` или отдельным методом.
2. Добавьте фазу в `GamePhase` при необходимости.
3. Переключайте фазу из `GameManager`.

### Заменить механику броска

Основная точка изменений — `BellController.Throw()` (направление, сила) и `ThrowableObject.OnCollisionEnter2D()` (условия попадания).

### Локализация

Тексты UI сосредоточены в:

- `MenuUI.cs` — меню и «О разработчиках»
- `GameManager.cs` — «Вы выиграли!», «Вы проиграли!», «Вернуться в меню»
- Объект сцены `StartText` — подсказка старта

## Известные особенности

1. **UI создаётся в runtime.** `MenuUI` и панель результата не хранятся как префабы в Assets — они генерируются в `Awake()`. При изменении вёрстки редактируйте соответствующие методы в коде.

2. **Автопоиск ссылок.** Если поля `GameManager` пусты, объекты ищутся по имени через `GameObject.Find()`. При переименовании объектов сцены обновите имена в коде или задайте ссылки вручную в Inspector.

3. **CharacterSwitcher отключён.** Не включайте его вместе с `GameManager` — возможен конфликт управления мышами.

4. **StartTextAnimation.** На объект подсказки перезапуска вешается компонент `StartTextAnimation` (анимация текста). Убедитесь, что скрипт присутствует в `Assets/Scripts/`.

5. **Бросок только по колокольчику.** Клик по экрану на фазе `Playing` не бросает колокольчик — только клик по collider колокольчика в `BellController.Update()`.

6. **Случайность броска.** Даже при неподвижном коте траектория имеет случайное смещение (`randomOffset`) — это заложено в геймдизайн.
